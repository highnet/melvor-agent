## [1.0.0](https://github.com/highnet/melvor-agent/compare/v0.1.0...v1.0.0) (2026-09-05)


### ⚠ BREAKING CHANGES

* ANTHROPIC_API_KEY is no longer read, and the Anthropic SDK is no longer a dependency. Objectives come from a Claude Code session attached over MCP, or they do not come.
* the heuristic planner is gone. It no longer picks the highest XP/hr candidate when the model is unavailable.
* dryRun and combatGateDryRun settings are gone. Arming now means the agent plays, and combat engages whenever the survivability gate passes. The gate itself is unchanged and still refuses any fight it cannot prove survivable - that is what keeps deaths rare, not a mode switch.

## 0.1.0

Initial working agent. Full history predates Conventional Commits and is in
`git log`; the short version:

- Adapter layer with the `ActionResult` contract — every action returns
  before/after evidence, because the game's own return types are inconsistent.
- 16 startable skills: 3 gathering, 6 artisan (one shared routine), 7 individual.
- Selling and shop purchases — the transitions the project exists for.
- Combat behind a deterministic survivability gate, advisory by default.
- Pure policy tier with 84 tests; generated `docs/API.md` with a CI drift check.
- Terminal dashboard and a local Hono service for durable state.
